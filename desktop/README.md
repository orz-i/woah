# 已废弃：Woah 桌面 / Web

自 **2026-10-31** 起，维护者将桌面 / Web 产品列为过期，不再维护或提供部署支持。当前交付目标仅 Android / iOS。请勿将本目录视为受支持的安装／运行入口，也不应新部署这里的服务。

本目录作为历史源码保留；第三方 vendor 的来源与许可证继续有效。本次没有删除源码、依赖、旧分支、数据或许可证，也没有修改／关闭任何已部署服务。

## 不等于安全修复或服务下线

历史 `api.py` 以及 Mac／Windows 启动脚本仍包含非 loopback 监听配置。桌面网络边界和模型加载问题因产品退出不再进入本轮修复计划，**并未被修复**。废弃声明不是继续使用旧实例的安全认可，也不能证明任何既有实例已下线。

本次只读快照在 2026-10-31 06:10 UTC 未观察到当前 Mac 上匹配 Python／uvicorn 的进程或 TCP 8002 监听；不覆盖其他机器、容器、端口或时间。若有既有部署，应针对实际实例另行核实停用与数据处理，不能按此快照推断。

## 仍需保留的移动工具

根 `pyproject.toml`／`uv.lock` 和 `tools/`、`models/`、`testdata/` 仍用于移动端模型准备、导出、契约测试、CI 与 golden 验证。某些模型源权重采用 PyTorch，不意味着它们随桌面产品退役。不得因此整体删除这些共享资产。

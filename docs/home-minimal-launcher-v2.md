# Woah 首页 V2 — 单任务专业启动器（真机反馈修订）

日期：2026-10-23
状态：实现依据，覆盖 docs/home-card-workbench-design.md 中与首屏 / 工具库相关的旧方案。
范围：Flutter mobile 首页；不改检测模型、追踪、预览与导出。

## 来源与判定

Android 真机截图证实 V1 存在实际产品问题：
- 首页单功能占用近整屏卡片，内嵌大头像和盾牌只是装饰，视觉像模板占位，不传达视频导入。
- 顶部品牌过高、卡片内容重复“隐私保护”“选择视频”等描述；主任务被装饰及大留白稀释。
- “全部工具”与主卡重复可用入口，工具库列出“智能裁切、人脸贴纸、人物特效”这类仅在编辑器中使用的操作，增加导航和理解成本。
- 只有一个真实独立任务，不应以工具库和不具备真实路由的功能来填充首页。

## 产品决定（替代 V1）

1. 首屏只放 **Woah 品牌 + 一张可点击的导入视频卡片**，不提供“全部工具”、工具网格、内置功能列表、底部导航或假的二级入口。
2. 视觉只保留专业媒体产品语汇：深石墨背景、单一低对比材质卡片、克制的金色交互强调、清晰的中文文字排版。不使用巨大人物图标、盾牌徽章、星星/轨道、角色与大型背景渐变。
3. 主卡可见内容缩减为 “导入视频” 与一句操作相关的短提示，例如“从设备中选择视频”。主卡整个区域是一个操作，不能有卡内叠加按钮。
4. 核心画面在不同设备上居中并控制占比：卡片短于屏幕高度约一半，宽度在手机上有明显边距；小屏可滚动但主卡不挤压到状态栏或系统安全区。
5. 保留长按 Woah 打开彩蛋，但不显示该隐藏行为的入口广告；保留原生文件选择、元数据探测、错误文案、成功后跳转保护编辑器和返回后重置状态。
6. 未来**真正上线第二个独立功能**后，才使用抽象的独立任务注册表、滑动卡片与分页；在单任务阶段不渲染轮播组件、位置指示或者空工具库。编辑器内部能力无论数量多少均不升级成一级入口。
7. 点击状态可见且可访问：响应波纹、重复点击防护、导入和探测时文字变化，失败反馈在卡片附近；支持系统字体放大和无动画偏好。

## 布局和交互约束

| 元素 | V2 规范 |
| --- | --- |
| 顶部 Woah | 左对齐、26–30sp 粗体，轻微金色品牌标识；不出现口号、副标题或额外工具按钮 |
| 主卡 | 约 250–310dp 宽，短于半屏的高度，低对比石墨表面，16–24dp 圆角；**无描边**，通过表面明度和底部投影区分背景 |
| 立体层级 | 使用由上至下逐渐柔和的外部阴影（正向 Y 偏移、较大模糊，主阴影偏底部），避免四周均匀描边和金色荧光；投影必须放在卡片裁切层外，不能被圆角剪裁 |
| 插画 | 仅小型 + 或简单上传/视频符号，不采用占用半卡的图像占位及额外盾牌 |
| 操作 | 整卡唯一点击 → 相册/文件选取；关闭／取消不进入编辑器 |
| 辅助文案 | 只写“从设备中选择视频”或同等动作指导，不承诺绝对隐私保护效果 |
| 功能索引 | 不显示 /tools，不列出智能裁切、贴纸、人物特效；删除当前无用路由与页面代码 |
| 状态 | picking/probing 时禁用卡片并更新提示；失败紧邻卡片；正常返回首页可再导入 |
| 兼容 | 320×568、360×640、390×844、大屏及文字放大不溢出；无循环动画 |

## 2026-10-23 真机反馈增补：无边框悬浮卡片

- 用户明确要求移除主卡可见边框，底部增加阴影并增强轻微悬浮感；保持简约专业，不增加发光装饰、第二重卡片或宣传文案。
- Flutter 验证：导入主卡装饰 `border == null`；卡片外层具有向下偏移的 `boxShadow`；触摸、忙碌和无障碍标签回归不变。

# Woah 青柠节拍 VI 与产品视觉规范

版本：Lime Beat VI 2.2 · 2026-11-04

正式交付：[15 页 VI 手册](deliverables/Woah-Lime-Beat-VI-v2.2.pdf) · [可编辑资产包](deliverables/Woah-Lime-Beat-Assets-v2.2.zip) · [整本预览](deliverables/Woah-Lime-Beat-overview.png)。延续浅色底与青柠主标识，首页缩小品牌尺寸、柔化卡片渐变；手册、JSON/CSS Token 与真机应用示例同步。

本规范取代 Quiet Frame 的主视觉配色与首页封面方向。依据为用户选定的[青柠节拍首页参考](assets/selected-home.png)。产品名称仍为 **Woah**，正式中文品牌名仍为「舞哇」。首页左右滑动卡片、相邻卡片露边、分页、整卡点击、品牌长按彩蛋和两个独立工作流保持不变。

## 1. 品牌表达

用明亮的练舞空间、完整的身体姿态和青柠色表达活力。字体与控件清晰、克制，让舞蹈影像占据主要视觉空间。淡紫作为辅助色，W 保留原造型，主 Logo 统一为 Ink / Lime / Chalk，移除旧深薄荷主版本。

- **主色**为青柠，不再以薄荷作为所有操作的统一强调色。
- **页面主背景**为近白的 Chalk；系统深色模式仍提供同一套青柠视觉的暗色配套，不新增外观切换入口。
- **人物与动作**是主要视觉，不增加巨大口号、角色、装饰星空、工具列表或首页导航。
- 状态必须有文字、形状或图标辅助；青柠、选中人物和品牌标识均不代表隐私保护已经完成。

## 2. 标识与字标

保留既有双侧 W 曲线、镜像关系和中心留白，沿用原生矢量源，不从生成图中描摹 Logo。W 与 Woah 的组合、首页位置和长按动作不变；产品界面仍只显示英文名称。

| 用途 | 背景 | W / 字标 |
| --- | --- | --- |
| 浅色首页 / 品牌主版本 | Chalk `#F7F9F1` | W 与 Woah 均为 Lime `#D8F54C` |
| 深色首页 | Ink `#17201C` | W 为 Lime `#D8F54C`，Woah 为 Chalk |
| 浅色应用图标 | Chalk | Lime W |
| 浅色启动页 | Chalk | Lime W |
| 深色图标 / 启动页 | Ink | Lime W |
| 系统着色图标 | 中性单色 | 颜色由系统决定，保留相同 W 几何 |

图标不烘焙设备圆角、发光和阴影。iOS Any / Dark / Tinted 插槽与 Android 自适应 / 单色 / 夜间资源结构保持不变。Wavi 保留原有形象与隐藏彩蛋交互，是独立插画角色，不替代正式标识；无需把现有 IP 像素强行涂成主色。

Ink / Chalk 单色标识作为辅助版本保留，亮色主版本优先使用浅白底与青柠 W / 字标；不再采用青柠底墨色 W 作为亮色应用图标。

## 3. 颜色与可读性

[palette.json](palette.json) 保存色值基准，运行时语义角色位于 `mobile/app/lib/app/theme.dart`。

| 色彩 | sRGB | 用途 |
| --- | --- | --- |
| Lime 青柠 | `#D8F54C` | 主标识、主操作填充、卡片底部局部渐变、选中分页 |
| Chalk 浅白 | `#F7F9F1` | 浅色页面与启动背景 |
| Ink 墨色 | `#17201C` | 浅色正文、青柠底上的文字与箭头、深色背景 |
| Lavender 淡紫 | `#DCD7FA` | 辅助容器与摄影服装点缀 |
| Olive 深橄榄 | `#50670E` | 浅色页面上的选中小字、细线与必要控件边界 |

建议以浅色空间和真实摄影为主，青柠集中在操作与卡片底部，淡紫小面积点缀。不要把青柠铺满所有面板，也不要让每个按钮都成为同等强度的主操作。

| 语义 | 浅色 | 深色 |
| --- | --- | --- |
| 页面 | `#F7F9F1` | `#17201C` |
| 面板 | `#FFFFFF` | `#222C24` |
| 柔和面板 | `#EEF1E5` | `#2B352B` |
| 主文字 | `#17201C` | `#F7F9F1` |
| 次文字 | `#46513F` | `#C4CEBC` |
| 弱文字 | `#5D6B53` | `#A3B297` |
| 主操作填充 / 前景 | 青柠 / Ink | 青柠 / Ink |
| 选中小字与线条 | Olive | 青柠 |
| 必要控件边界 | `#768369` | `#7B8874` |

浅白底青柠用于品牌主标识；正文与必要操作提示继续采用深色。主操作使用 Ink 前景；浅色背景上的选中小字、功能图标与线条使用 Olive。分页保留原有形状，在青柠选中胶囊外加深色细边界。普通文字以 4.5:1、必要控件边界以 3:1 为纯色检查下限；照片叠层另做真机视觉检查。

错误、警告、成功使用独立语义角色与明确文案。视频原始像素、人物特效 ARGB、遮罩、用户工程、同步与导出算法不从 VI 配色中取值；原有琥珀金特效 `0xFFF5A623` 保持原值。

## 5. 字体、图形与交互边界

- 沿用原生系统字体与现有图标库；不引入新字体包和重新绘制的控件图标。
- 首页 Woah 缩小为 24sp，W 为 28 × 17.5dp，符号与字标间隔 8dp，品牌行在默认字号下占 36dp，放大字号可自然增高。保留 20sp 卡片标题、13.5sp 说明与两行说明槽位；标题 w700，标题和说明采用强制 Strut 行高，统一第一行文字基线。检查滑动中间状态与放大字号，不能只比较文字框顶部。
- 圆角、间距、卡片尺寸与阴影模型沿用现有实现；不通过增大卡片、添加新口号或修改导航表现活力。
- 触摸目标沿用至少 48dp 的现有约束；保留忙碌状态、防重复触发、失败提示、取消与返回行为。
- 不新增持续浮动、旋转、音乐跳动或自动播放；现有动画与减少动画偏好继续生效。

## 6. 全流程视觉应用

首页负责传达活力；编辑与对比页面使用同一套浅白、青柠与淡紫角色，控件位置、步骤、参数及手势不变。主操作使用青柠填充配 Ink 文字，未填充的选中小字使用具有对比度的 Olive。真实视频舞台保持黑色和原始颜色，不给视频套 VI 滤镜。

导出、结果与错误反馈沿用现有状态及按钮，仅接收新的语义颜色。原生相册 / 文件选取器不重建。系统明暗模式继续由 `ThemeMode.system` 管理，切换时保持当前卡片页码与工作流状态。

隐私打码配置页的预览工具条悬浮在实际视频画面右上角，距画面边缘 8dp，横竖画面及留边布局均跟随视频边界。只显示操作图标，移除“原片预览”、保护人数与操作说明的常驻文字；长按提示与读屏状态保留。悬浮图标与底部选中工具、时间轴和原声开关共用 `editorSelection` 色彩角色：浅色为 Olive `#50670E`，深色为 Lime `#D8F54C`，不单独使用另一种亮绿色。采用透明悬浮与轻微阴影，无底色或圆角容器；保留 48dp 触摸目标。原片 / 裁切切换、恢复默认、清空对象及主角确认流程沿用原行为。

## 7. 资源重建与验证

- `python tools/brand/generate_lime_beat_assets.py`：从现有 Android W 路径重建品牌 PNG、SVG、Android 启动器与 iOS 图标 / 启动页；需要 Pillow。
- `tools/brand/generate_quiet_frame_icons.swift` 保留历史文件名，配色已同步新方向；macOS 仍可从原 W 曲线重建图标。
- `python -X utf8 tools/brand/verify_quiet_frame_assets.py`：历史命令名保留，现检验 Lime Beat 色值、封面引用、资源与特效隔离。
- `python -X utf8 tools/brand/verify_system_appearance.py` 与 `verify_launcher_icon_appearances.py`：检验系统明暗资源、图标格式与外观。
- Flutter 静态分析与现有主题、首页、比较控件、导入 / 编辑 / 导出相关测试；Android 真机截图对照选定参考。

旧 Quiet Frame 文档中的测试数量和设备截图只属于旧基线，不能作为本轮通过证据。本轮结果与限制记录在[验证记录](verification.md)。

# Woah · Wavi IP 与彩蛋页 · Quiet Frame 配套设计

日期：2026-10-29
基线：`feat/quiet-frame-vi-v1-1` / `0e2f785`
实施分支：`feat/quiet-frame-easter-egg-ip`
状态：原创 IP 候选与移动端彩蛋页面实现；**不代表已经完成 IP 商标 / 外观法律检索，亦未通过设备真机完整验收**。

## 设计决定

- **名称**：内部角色名 `Wavi`，中文描述为“节奏小精灵”。与 Woah 品牌 W 标识独立；**不改变已确认的对外品牌名 Woah**。
- **角色形状**：小型弹性薄荷色身体、开放式舞动触须、象牙白面部与深墨表情；可爱但不是安全盾牌、保密认证，也不是视频中的人物框线。
- **原始绘制**：`tools/brand/generate_wavi_mascot.swift` 使用 CoreGraphics 从自主定义的曲线和颜色角色生成 4 张透明 PNG（512 × 512），所有表情保持相同形体比例。资产可以重建，无字体、图库与外部角色授权依赖。
- **姿态**：`idle` 待机、`peek` 转身、`joy` 开心、`wave` 挥手。后续如需精细化 SVG/插画师交付，应以此几何作为比例基线重新输出可编辑路径，而不是拿产品图标直接加表情。
- **品牌颜色**：墨黑 `#0B1415`、薄荷 `#78DCC7`、深薄荷 `#216A5E`、珍珠白 `#F2F6F3`。仅作为彩蛋页面插画与排版色，不触碰隐私遮挡颜色、segmentation mask、追踪或视频导出。

## 页面与交互

1. 首页继续**长按 Woah 品牌**打开彩蛋，主流程不增加入口与提示。可以用系统返回或页面顶部的小号关闭操作退出。
2. 彩蛋仅显示一个 Wavi、很短的欢迎文案和一段小惊喜。**轻触角色**切换短句与姿态；不再使用大按钮、金色纸卡、星空、强制启动动画。
3. 所有触发操作防重复。角色切换只在触发时有单次 200–240ms 的轻量过渡，**无常驻循环动画**；系统要求减少动态效果时立即完成切换。
4. 继续保留免费开源与谨防误导的短说明、版本号及提交信息，用作辅助内容，不喧宾夺主。
5. 页面能纵向滚动，避免 320 × 568、小屏及大字号时内容被裁切；入口有语义描述和可点击目标。此角色绝不可用于隐私是否已保护成功的判断。

## 明确不做

- 不修改 App Icon、品牌 Logo，不将 Wavi 插入每帧视频预览或人物选择遮罩。
- 不更改文件导入、导出、双视频同步、媒体存储、原生性能和保护算法。
- 不添加三维实时渲染、音效常驻播放、联网下载或新的首次启动等待。

## 验收条件

- `flutter analyze` 和 Flutter 全量 widget tests 通过，尤其长按入口 / 系统返回、反复点击、减少动态、小屏大字号。
- iOS Simulator 与 Android 设备上，角色透明边缘、字体、页面上下安全区以及深色对比度无异常；完整真机视觉反馈仍需后续独立确认。
- 在导出 UI 中不得把 Wavi 或绿色表情用作保护完成的技术声明。

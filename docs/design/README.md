# Woah 设计基线

当前采用 [Lime Beat 青柠节拍 VI 与产品视觉规范](lime-beat/README.md)，经用户于 2026-11-04 选定。新开发和视觉验收以该规范、其选定参考及当前运行代码为准。

首页维持左右滑动任务卡片与现有交互；亮色采用浅白底与青柠主标识，图标、启动页配套保留。正式 VI 2.2 同步首页品牌缩小与浅青柠渐变；深色配套色值不变。

`quiet-frame-*`、`mobile_warm_flow`、`home-cinematic-cover-cards-*` 和 `export-cinematic-progress-*` 文档保留历史实现与检查记录。其旧配色、摄影和“已通过”结论不能直接继承为 Lime Beat 的视觉依据；工作流约束在没有新产品决定时继续适用。

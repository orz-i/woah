问题：隐私编辑器底部工具栏、保护范围和遮挡样式以绿色与灰绿色作为主要的选择反馈；浅色主题尤其难以瞬间区分“选中、未选中但可用”。这与视频人物 Mask 的渲染质量无关，也不意味着绿色 UI 选中能证明视频隐私保护成功。

## 设计处理原则

- **非颜色单一状态信号**：选中项增加约 24–32dp × 3dp 绿色短线，图标和文字继续使用当前主题编辑选中色；未选中可用项改用 textSecondary，不按禁用色处理。
- **仅少量重点控件增加薄色背景**：底部工具与调节属性的选中图标采用小面积 editorSelectionSubtle；不增加整排大底座、厚重边框或重复卡片。
- **主题对比度**：浅色选中 #216A5E／未选中 #435E59／背景 #F2F6F3；深色选中 #78DCC7／未选中 #B4C8C6／媒体背景黑。计算 sRGB 对比度：浅色选中约 5.86:1、未选中约 6.45:1；深色选中约 12.86:1、未选中约 12.02:1。具体 UI 与媒体照片叠层仍要真机复核。
- **状态读屏**：工具栏/保护范围/样式原先已有 selected 语义；为调节属性与画幅比例补上 Semantics selected。标记只代表界面所选工具、模式或样式，不表示已完成实际保护。
- **大字体**：320×568 / 1.6× 和 2× 文本放大回归发现原固定行会溢出。缩减装饰间距，样式名称在超窄状态限制单行并可省略，但读屏保留完整名称。

## 其他页面巡检结果

| 页面与组件 | 先前状态问题 | 处理 |
|---|---|---|
| 隐私编辑器四个底部工具 | 只改变颜色和字重 | 选中图标淡色背景、下划线、未选中更清晰 |
| 隐私编辑器全身／人脸范围 | 只改变文字和图标颜色 | 32dp 短线、选中文字加粗 |
| 隐私编辑器马赛克／模糊／色块／渐变 | 只改变颜色，放大字体可能溢出 | 24dp 短线、空闲文字可读，压缩装饰留白 |
| 隐私编辑器调节属性 | 缺少明显几何选中标识 | 图标淡底、短线、selected 语义 |
| 隐私编辑器画幅比例 | 选中细边框仍不醒目 | 2dp 选中描边、短线、selected 语义 |
| 舞蹈对比参考／目标调整选择器 | 分段控制背景始终透明 | 仅选中段使用 editorSelectionSubtle |
| 舞蹈对比位置／速度校准选择器 | 同样只靠文字颜色 | 仅选中段淡底 |
| 舞蹈对比音乐锚点 1／2 | 当前步骤仅文字变色 | 当前锚点浅底色 |
| 舞蹈对比视图／镜像菜单 | 选中只靠绿字 | 选中行尾部追加 17dp 勾选 |
| 舞蹈对比 A/B 循环 | 只改变图标颜色 | 启用时增加小面积淡底 |
| 贴纸、用户效果色 | 原有清晰的选中描边与勾选标志 | 保持不变 |
| 对比时间轴区间和 A/B 控制柄 | 已有轨道色块、控制柄与轮廓区别 | 保持不变 |
| 导出、结果、首页轮播 | 操作状态、进度或长短页码有形状／填充表达，非同类单选组 | 保持不变 |

## 真机复核建议

深浅两种系统主题下打开隐私编辑器并切换全身/人脸、遮挡样式、四个底部工具、画幅和调节。确认选中有明确形状反馈、未选中仍可辨、面板切换不跳动。对比页面检查参考/目标、位置/速度校准、锚点、视图菜单和 A/B 循环。额外检查大字体与读屏选中状态，确认用户视频处理结果未变化。

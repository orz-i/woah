# Shared privacy-class continuity

The pure Rust port follows the canonical Android class tracker. It does not assign
person identity. The first nonempty hard selection is immutable; unresolved
observations protect by default and do not teach prototypes. Constants and cached
mask sampling preserve the native behavior.

The frozen oracle was generated by a test-only copy of the original Kotlin
implementation before replacing its production consumer. It contains 1,024 steps
in 16 deterministic scenarios, with caching enabled and disabled, actual mask
bytes, ordered roots, crossings, reversals, misses, merged observations, new
entrants and misleading later hard labels. Rust compares all decisions, unknown
flags, evaluation counts, root state, prototype Float32 bits and mask bytes.
See `crates/frame-kernel/testdata/privacy-class-native-v1.json` for binding.

This initial commit exposes the safe Rust algorithm only. Native consumers and
C transport migrate separately; it does not claim completed production migration
or final device regression acceptance.

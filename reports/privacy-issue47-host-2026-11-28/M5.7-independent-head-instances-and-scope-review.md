# M5.7 — Independent head instances and scope review

Status: local research checkpoint, not release accepted. Existing PR #48 / Issue #47, base `33590224`. No production activation; no remote CI prerequisite.

## Mechanism and retained decision

A single-class head detector produces independent current head rectangles even when person segmentation is merged. FrameKernel owns tensor decoding, reciprocal view fusion, mask ownership, unique reciprocal temporal links, two-sided bounded identity evidence and geometry arbitration. The host transports tensors and reuses scene masks. The head-only replacement arm regressed previously reviewed coverage and is rejected as a unified candidate; it remains a standalone comparison. The unified entrypoint exposes only the opt-in arbitration arm, with dual view. No new default model dependency, mobile runtime change or identity-clock activation.

Research weights (outside Git): `trysem/YOLOv8_head_detector`, nano 12 MB and medium 99 MB ONNX. The [model card](https://huggingface.co/trysem/YOLOv8_head_detector) declares MIT and identifies SCUT-HEAD training and an Ultralytics YOLOv8 base; the [base model](https://huggingface.co/Ultralytics/YOLOv8) declares AGPL-3.0. Upstream, data and redistribution rights are not cleared for Woah distribution. Hashes are pinned in the tool and summary. Medium is not selected: it recovered the same 17 Baganda frames as nano with substantially greater measured inference cost.

## Actual results

Nine unique video streams were computed for thirteen target replays, plus one medium comparison. Four references use M5.6 combined geometry, nine use M5.4 default geometry. All thirteen preserve canonical body state. The final arbitration build reuses earlier stream evidence with identical fusion and reciprocal links; the owner algorithm is unchanged. Fresh integrated Baganda and Danzon runs reproduce candidate frame rows exactly and require zero extra person-segmentation calls for the head stage. No fresh full-pipeline run is claimed for the other eleven cases.

Source-reviewed findings:

- Baganda: all 17 newly placed frames have complete reviewed head envelopes; a contiguous 15-frame gap is restored. The fixed grid improves 3/11 to 4/11. Neighbor envelopes were not annotated for the added samples.
- Swing ID7: four added regions, three complete and one 97.96% complete; maximum checked neighbor overlap 85%. A previously complete sample falls to about 89% coverage. This prevents default adoption.
- Danzon fixed grid: 10/12 to 12/12 complete; maximum checked neighbor overlap 100% to 64.71%.
- Ensemble fixed grid: 8/12 to 9/12; the previously reviewed six-frame window remains 6/6, the 13 changed-frame review remains 13/13, but an older nine-sample profile audit falls 9/9 to 7/9. A previously missed target-head sample improves from 78% to 100% while labeled neighbor overlap falls from 100% to zero.
- Original group mirror fixed changed-sample review: 2/5 to 4/5, max checked neighbor overlap 61.70% to 22.22%. Basque long gaps remain.

These are sparse and selection-conditioned source rectangles, not dense semantic ground truth. Final coverage count is not an identity or release acceptance metric.

Fresh integrated head stage: 550 calls / 17.57 seconds of inference in Baganda, 600 calls / 24.43 seconds in Danzon. Total host runs ~79 and ~43 seconds under concurrent load. Full cold versus historical times are not controlled performance comparisons. Standalone nano and medium Baganda streams both achieved 10/11 fixed-grid detector recall at IoU 0.5, with different misses; identity recovery is still 4/11. Two-model work stops here.

## Scope correction

Original Issue #47 requires multi-person ownership, long occlusion re-entry, partial visible head recovery, clothing competition and actual cross-platform export. Before M5.7, the PR had 24 commits and 65,498 additions (53,485 report lines, 9,392 FrameKernel lines, 2,620 tools lines, and one iOS lockfile addition). The local algorithm has made measurable gains, but implementation has drifted toward many independent head/geometry experiments and high-volume evidence records while long-duration recovery and the production candidate remain incomplete.

A direct diagnosis of the unresolved Baganda 165-frame interval is more valuable than another detector branch: the nano stream contains an 82-frame anonymous reciprocal head path (129–210), with 33 current raw owner matches but no canonical target-body observations. Existing dense appearance evidence independently votes for root 10 on the exact same raw body on seven frames in that path (192, 193, 195–198, 205). Three fixed-grid source checkpoints within the path agree with the detected head. This is a concrete head/body reconnect opportunity, not a proven long-range identity assignment. Other fixed-grid detections in the long gap are also visible; no ground-truth labels were used to assign identities.

Next work is bounded: reuse the existing head path and dense identity votes to test one shared identity reconnect mechanism, with competing root/merge evidence and independent source audits. Prioritize Baganda and Basque; then run the full existing 13-target comparison to decide retention. If identity proof cannot support the missing intervals, record the failure instead of growing geometry branches. Do not develop another head detector or more case-specific sticker fallback. Keep only one opt-in candidate; the compact-rival and head-only controls are not deployment candidates. Require an explicit decision about quality, cost and model rights before mobile integration. Android real device and iOS simulator export remain outstanding.

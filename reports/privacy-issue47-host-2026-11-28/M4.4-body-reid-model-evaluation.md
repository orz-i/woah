# M4.4 — independent body ReID model selection

Base `7f3904ad` (M4.3). **Research checkpoint only. No ReID model is approved for runtime integration.** Previous canonical tracking and the experimental M4.3 coverage lane remain unchanged.

## Question and pinned models

Evaluate whether an independent appearance encoder provides sufficiently discriminative evidence for same-clothing dancer re-association, with head-reduced inputs. In particular, a high retrieval rank is insufficient unless the selected root also wins against competing current proposals and all other initial roots.

## Frozen protocol

Use the pinned Basque (sliced at first unique initial selection) and Swing fixtures, unchanged initial raw indices and previous M4.3 replay. Decode with the existing production detector and require exact raw box equality and source/frame hashes. Basque target only (ID0); Swing two persistent partners (ID6/7). Exclude initial seed frame: Basque 9 later selected landmarks (8 have a supported raw positive), Swing 22 later partner landmarks (21 have a supported raw positive). A correct retrieval supports the selected source point without supporting its negative point; other outcomes include unconfirmed, negative and ambiguous. These sparse body probes do not certify whole-head coverage or every frame's identity.

All crops blank their top quarter and all face envelopes detected on current raw proposals. `headblank` retains background for a diagnostic ablation; `exclusive` additionally excludes all pixels not exclusively supported by that person's raw mask. This is head reduction, not proof that every undetected face pixel has been removed. No unmodified full-face crop is used for the encoder. The headblank result may depend on surrounding scene/person context and is not a deployment candidate.

Test single seed, early reference pooling (first five consecutive samples, each exact same-root canonical observation and FrameKernel reciprocal proof), and early reference + three-current-sample pooling. The latter averages current descriptors only along an anonymous, unique reciprocal mask triplet with no merge/split, otherwise keeps the current descriptor. The proof comes from M4.3, extracted without changing its two-anchor requirement; no later source annotation enters association. Basque selected root has five seed samples, Swing ID6 five and ID7 one. Qualified anonymous query triplets: Basque 52, Swing 46 across the candidate pool.

Rust exposes stateless research clothing descriptor extraction (existing M4 exclusive sampler, four square-root histograms), cosine similarity (minimum over four blocks for clothing; one block for embeddings), and two-way ranking over all valid candidates/initial references. Missing/zero/nonfinite descriptors cannot be matches. An absent competing score or tie does not establish a reciprocal match. Fixed diagnostic gate: similarity >=0.65 and row/column margins >=0.05. Equal-weight fusion is a frozen evaluation ablation, not a calibrated production policy. These scores are not probabilities and common thresholds do not imply equal cross-model calibration. No tracker/session mutation; no model or runtime dependency in FrameKernel or mobile.

All listed reciprocal matches were correct by the sparse source checks. Other tested combinations are not uniformly safe: e.g. 0288 headblank triplet accepts two correct and one unconfirmed Basque result. The initial-only clothing baseline has one unconfirmed accepted Swing result; pooling removes this in the listed policy. Complete metrics and selected diagnostic rows in `m44-summary.json`.

Basque's immutable clothing rank is often already right, but competing similar seeds prevent acceptance. 0287 exclusive confirms one later correct raw candidate with the *single* seed; after early and current pooling it confirms none. 0288 exclusive confirms one later correct candidate with pooled evidence. The DanceTrack-specialized encoder is not a reliable substitute. **No new validated continuous identity or protected head region has been established.** Swing's strong retrieval competition does justify testing 0287/0288 as independent secondary cues, not replacing M4's already strong 23/24 observed identity landmarks. Do not promote any model from these sparse data.

## Numerical precision finding

On the same 16 exclusive head-reduced Swing crops from a single source sample, OpenVINO CPU default selected FP16 execution. With cosine >=0.99999, 0287 produced 3 near-duplicate pairs out of 120 and 0288 produced 10/120. Explicit FP32 produced 0/120 for both; all full FP32 evaluations had zero near-duplicate within-frame pairs. Preserve execution precision and output-health checks in later runtime comparisons. This is observed backend/model behavior, not a universal FP16 claim.

## Engineering verification

220 Rust tests pass, 1 ignored; strict Clippy, fmt, Python syntax, ABI v1 passed. New tests cover invalid/nonfinite/zero descriptors, identical ties, absent competing scores, equality to existing clothing sampler, and anonymous triplet paths. The Release binary hash matches the exact model-evaluation library. Four representative real-model M4.3 replays (Basque ID0, Swing ID6, group ID4, single affine) reproduce both arms exactly, including all tracker snapshots and sticker outputs. No additional runtime retrieval branch, native model, or application dependency was added. The existing iOS CI dependency issue is separate.

Next: use genuinely independent pose-normalized body-part evidence (explicit torso/lower-body correspondence with current visibility, not more color-bank growth), then test across frozen post-occlusion tracklet candidates and a further crowded holdout. Before promoting a neural cue require a source-audited continuous re-association with zero accepted wrong/unconfirmed identities on those held-out samples and head coverage/neighbor quality evidence. Do not activate the new interfaces in native sessions.

## Reproduction

The experiment runner is `tools/privacy/evaluate_body_reid.py`. It checks the model files' SHA-256, source/frame/fixture hashes, model hashes, and exact original raw detector boxes. Reports only ranks/scores and audits. The local isolated environment used Python 3.12.14, numpy 2.2.6, Pillow 13.0.0, ai-edge-litert 2.4.1, OpenVINO 2025.4.0, torch 2.15.0, re-ID 0.1.0. Install the tagged re-ID wheel and local dependencies in a separate research venv; no repository or mobile dependency changes. OMZ IR files are at `https://storage.openvinotoolkit.org/repositories/open_model_zoo/2023.0/models_bin/1/<model>/FP16/<model>.xml` and `.bin`. DanceTrack safetensors is from the release catalog's `https://storage.googleapis.com/com-roboflow-marketing/trackers/trackers_reid_finetuned_encoders/reid_dancetrack_osnet_x1_0/weights.safetensors` (local filename `dancetrack-osnet-x1_0.safetensors`). Exact hashes and runtime versions in summary and evaluator; keep all weights local.

```sh
cargo build --release --manifest-path crates/frame-kernel/Cargo.toml
python tools/privacy/evaluate_body_reid.py --library crates/frame-kernel/target/release/libframe_kernel.dylib \
  --fixture "$BASQUE_MANIFEST" --labels "$BASQUE_LABELS" --reference-replay "$M43_BASQUE_REPLAY" \
  --selected-id 0 --model-dir "$MODEL_DIR" --output basque-reid.json
python tools/privacy/evaluate_body_reid.py --library crates/frame-kernel/target/release/libframe_kernel.dylib \
  --fixture "$SWING_MANIFEST" --labels "$SWING_LABELS" --reference-replay "$M43_SWING_REPLAY" \
  --selected-id 6 --partner-id 7 --model-dir "$MODEL_DIR" --output swing-reid.json
```

Optional `--precision auto` reproduces the backend-default precision ablation. Use the existing C7.3 labels, Basque sliced at frame 25 with reference label timestamps shifted by 1s; Swing unchanged target-role labels rewrapped as reference. No later labels used for matching. Full uncompressed reports remain in the local issue47 research directory.

# M5.3 — required head extent and current rival competition

Base `9c61fde4` (M5.2). Research-only opt-in geometry experiment on top of the M5.1 profile repair. No change to the canonical tracker, offline identity consensus, fragment recovery, or native compositor.

## Mechanism

Keep the current target's required head rectangle and minimum enclosing square radius fixed. The shorter axis has a bounded translation interval that still encloses the target rectangle. Each rival rectangle's overlap fraction on this interval is piecewise linear. Evaluate interval endpoints, breakpoints and pairwise crossings to minimize the maximum overlap, then total overlap, then movement from the centered placement. The render's existing 1.02 sampling margin is included in the calculation. This is the exact one-axis minimax for the supplied extents and fixed nominal radius; it is not a semantic pixel segmentation. Report the unavoidable intersection of the required rectangle itself, centered overlap and best square overlap separately. A residual >10% overlap on supplied evidence is a conflict, not a successful coverage result.

Current rival detector faces remain negative evidence. If a face has unique current mask-core ownership and ordinary current head placement yields a complete connected cap, add the larger current head rectangle as negative evidence too. Missing current rival observations cannot certify safety. The solver accepts optional already validated local negative geometry from the research adapter; it never creates a target identity or modifies the required target extent.

In the Ensemble source one nearby background head is missed by the scene proposals. Two current upper-body context crops of different widths recover a separate local instance. The first local ear-cap path establishes a complete current head rectangle; the second independently inferred mask corroborates it in their common view. Require common-view raw mask IoU >=0.60, unique candidate margin >=0.20, second confidence >=0.45, a minimum of 20 first-cap scene-grid support cells, >=90% retained support in the second mask, and no existing scene mask owning more than 10% of that first cap support. Both views must contain the cap away from their borders. This is **negative evidence only**, not a new positive recovery or identity assignment. No label or prior head geometry selects the local proposal.

The host applies a spatial shift only after the existing profile repair succeeds, if the new measured competition improves, residual is <=10% on supplied evidence, no nearby raw head candidate is missing its face measurement, and a current complete rival cap or corroborated local cap is available. The radius and required extent stay unchanged. When these conditions fail the experiment keeps the original M5.1 candidate; it does not deem that candidate safe. Direct-frame diagnostics are never applied. In a rejected direct diagnostic, the tentative target cap may be measured with rival detector ellipses omitted **only for diagnostic extent comparison** (all raw masks retained); the competition calculation receives all original rivals. No native policy promoted.

## Reproduction

Use the pinned M5.1 canonical reference and final release library:
```sh
python tools/privacy/evaluate_profile_head_geometry.py --library "$LIB" \
  --fixture "$MANIFEST" --reference-replay "$CANONICAL" \
  --model-dir "$MODEL_DIR" --head-competition --output profile.json
```
For the existing Danzon direct diagnostics add `--diagnostic-indices 50,75`; for Ensemble add `--diagnostic-indices 25`. Compare the profile candidate against the unchanged M5.1 profile control (not the original canonical region) using the existing source head rectangle auditor. To reproduce M5.2 without the new experiment use `--fragment-window --fragment-only`.

# M4.3 — offline reciprocal raw tracklet proof

Base `c6118a57` (M4.2). Research-only `--offline-tracklet` with actual M4.2 policy enabled in both arms. The retained candidate is a bounded retrospective coverage experiment; **long-gap re-identification and new coverage quality do not pass**. Native consumers remain unchanged.

## Global tracklet experiment — rejected

A source-independent host diagnostic built continuous raw-mask tracklets: adjacent raw IoU, reciprocal margin and box consistency, with a two-sided preflight that quarantines merged/split proposals. The experimental inter-tracklet scorer compared multiple endpoint clothing descriptors and forward/backward bounded motion projections, and required a unique incoming and outgoing match. The first version constructed too many fragments; the revised variant excludes weak/merged nodes but keeps them as negative evidence. Neither variant uses source landmarks to associate.

Basque (sliced 275-frame fixture): revised graph has 254 tracklets, 14 quarantined raw nodes, 32 reciprocal gap edges. Selected root path contains 73 current observations and ends before the actual occlusion. Later long tracklets do support the selected source landmarks, but the first plausible later destination has competing predecessor score 0.918 vs 0.720 from the original target (another forward candidate 0.689). Frozen seed/tracklet clothing comparisons also sometimes prefer the similar-dressed neighbor. Forcing a gap edge would not establish identity. Swing graph similarly retains only 45 and 2 frames for the two original seed paths, far below M4.2. Global graph rejected rather than lowering competition margins or using later annotations as anchors.

## Implemented bounded two-anchor proof

The host freezes exact canonical raw observations at the end of the first pass. FrameKernel accepts a 3–8 sample window spanning <=250 ms, strictly increasing real sample times with adjacent gaps <=100 ms. Every intermediate sample must have a real raw proposal with confidence >=0.50, raw mask IoU >=0.55, box IoU >=0.45, and a reciprocal row/column mask margin >=0.15. All raw masks remain competing evidence, including weak ones. Reject merged/split proposals that contain two distinct adjacent masks, and require the path to end at the independently observed right anchor. Host excludes any raw proposal committed to another observed identity or quarantined as a body merge.

For missing coverage only, require a direct face anchor within 150 ms and a current face measurement on the selected raw mask. Rust plans two current-image local crops (5x and 7x maximum measured radius); both detector measurements must agree with the primary center/scale and the anchor-relative body geometry. Each must have >=12/16 owner core samples and >=4 distinct cells, and every rival mask must have <=4/16 support. The current-only union and head-cap placement generate an independent proposed region. No interpolation through missing raw detections and no updates to canonical tracks, face clocks, history, or subsequent placement. This is a geometric square experiment; the native ellipse/mask compositor is not assessed.

## Inference reuse

Dense identity features and votes are calculated for every initial root, not just the selected target. The prior host workflow reran the same dense analysis when testing another target on an identical clip. New opt-in `--shared-dense --shared-reference` reuses this evidence only when source fixture/model/library hashes, protected roots, all canonical frame times, raw boxes, track snapshots, merge evidence, actual frame hashes and local weights agree. Each selected target still runs its own recovery selection. Altering a canonical identity in the shared reference negative control rejects reuse and writes no result. No image crops or embedding vectors are persisted by the shared evidence.

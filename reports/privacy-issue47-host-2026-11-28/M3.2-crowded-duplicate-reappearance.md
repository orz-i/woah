Base `f6a0f11b` (M3.1). Explicit host-only `--crowded-recovery`; baseline retains all M3.1 options. No native runtime activation.

## Observed failure

The black-top dancer (group ID2) becomes largely hidden behind the foreground pink-top dancer. Source review shows an earlier accepted direct measurement on the foreground raised hand; its owner mask and rival mask both support the false observation. Exclusive garment sampling rejects it. At the end the black-top dancer's face is clearly visible again, but the current segmentation emits two overlapping proposals, one full body and one upper body. Their smaller-mask containment is 84.97%; body box IoU is 0.317 (the smaller box is substantially contained). Both produce coincident fresh face measurements. Existing exclusive sampling treats the duplicate as a competing person and rejects them. This failure cannot be fixed by extending the corrupted direct clock or treating an old mask as current.

## Shared algorithm

- Only when ordinary coverage recovery fails for a retained occluded/reacquiring selected identity in a crowded scene, find the most recent historical canonical direct observation with an exclusive current garment descriptor. Freeze the last 2–3 verified observations in the existing bounded garment root sampler; use existing 950ms–2s reappearance interval and unchanged similarity/competition thresholds.
- FrameKernel preflights all uncommitted current raw proposals using body containment and raw foreground-mask containment (both >=80%, minimum confidences 0.40/0.30). Only plausible pairs trigger current face inference. The pair must independently pass current face support, agree on center and scale, have no third current mask supporting either face, and not be owned by an observed foreign track. Ambiguous multiple pairs abstain. The raw tracker observations are never modified.
- Coalesce only the certified pair's mask for the coverage-only garment decision. All other raw masks remain negative evidence; all available other garment candidates remain rivals. Require the existing reappearance chooser to select this pair. The current local face crop is planned by Rust at a third scale and must independently corroborate both measurements and the union mask. The final square encloses all three current measurements and connected support, and rejects overlap with other currently detected face centers. No recovery-derived canonical observation, appearance update, projection lease, or temporal seed.
- Cost is limited by the geometric preflight: only one qualifying event in the original ID2 run, six per-instance current face calls and one additional localized face call. Historical descriptor evaluation may require historical detector calls; mobile wall time is not measured.

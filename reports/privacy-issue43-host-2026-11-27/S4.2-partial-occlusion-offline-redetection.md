# S4.2 — optional offline partial-occlusion re-detection

Status: **host research only, disabled by default; one original adjacent frame improved, mirrored case did not improve. No production or mobile acceptance.** Baseline 0a7b318d.

## Evidence and implementation

The striped-top selected dancer is partially obscured at the foreground boundary near the reappearance. Source HD diagnostics show smaller inconsistent proposals at 109, no qualified current owned face at 110, and two current local instance/face observations at 111. The coarse full-frame mask at 111 overlaps the detected face center but has a foreground boundary in the neighboring prototype cell. This is not proof of identity or full visibility. Existing global and 60% tile inference did not supply a separate face/instance there.

The new Rust experiment uses an independently qualified later garment reappearance only to plan two different current-image crop sizes. It is limited to the immediately preceding missing frame, gap <=150ms, and within the existing independent 2s reappearance root age. It does not copy later geometry or extend the original prediction lease. Both crops must supply a fresh owned per-instance face, exclusive current garment/mask evidence, compatible face center/scale, and competitive garment scores against frozen earlier direct roots and available historical/current rivals. One crop must have body confidence >=0.50 and both >=0.40. Current coarse masks must have an actual boundary rather than solid foreground; all current per-instance selected full-frame faces veto overlap. A successful output is a square covering the union of the two current required extents. It may not seed another retrospective probe, direct-observation clock or identity update. Unresolved cases abstain.

The host uses a separate explicit --retro-partial flag; default host path and production mobile code remain unchanged. The new square is a bookkeeping render marker only; ellipse-mask coverage is not validated for this lane.
